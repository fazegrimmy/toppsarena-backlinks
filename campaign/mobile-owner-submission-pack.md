## Safe mobile steps

1. Tap a submission URL and choose the free tier/category.
2. Paste the website title, URL and accurate description above.
3. Use **your own real operator details** for mandatory owner fields. Do not publish a personal address just to claim a website listing.
4. If prompted for CAPTCHA, 2FA, domain ownership or a screenshot, complete it yourself.
5. Keep the confirmation email or public listing URL. A 'submitted' toast is *not* a backlink.
6. Once an actual public listing page appears, provide its URL for independent HTML anchor verification. Never count a page that only redirects or mentions TopPSArena without linking.
